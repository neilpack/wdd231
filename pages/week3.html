An event is something that happens on the page, like a click or a keypress. JavaScript can listen for an event and run a function (called an event handler) when it happens.

Every example below uses the same pattern:

element.addEventListener("eventName", functionToRun);

1. click

Fires when the user clicks a button (or presses Enter/Space on it).

Button clicked: 0 times

2. input

Fires every time the value of a text box changes, on each keystroke.

Hello, ...

3. change

Fires once, after the user finishes picking a new value, like choosing from a dropdown or checking a box.

You picked: nothing yet

4. submit

Fires when a form is submitted (clicking the submit button or pressing Enter in a field). We listen on the form, not the button.

The form has not been submitted yet.
